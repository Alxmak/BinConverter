# Tweak Firmware

Десктопное приложение для Windows для работы с дампами прошивок eMMC (программаторы UFPI, TNM5000, RT809H и т.п.): разбивка файла на части, сборка обратно и проверка целостности по SHA-256.

## Возможности

- **Конвертирование** — разбивка `.bin`-дампа на части заданного размера (пресеты под конкретные программаторы или свой размер), с проверкой SHA-256 после завершения и контролем свободного места на диске.
- **Сборка файла** — обратная склейка частей в один файл по любой части цепочки, с опциональной проверкой итогового хэша.
- **Проверка SHA-256** — сравнение двух файлов по хэшу.
- Пауза/продолжение и отмена для длительных операций, единый журнал событий с сохранением в файл.
- **Автообновление** — фоновая проверка новой версии на GitHub (раз в день), баннер с предложением обновиться, тихая загрузка и установка без участия пользователя.
- **Локализация** — русский и английский, переключение языка вживую без перезапуска.
- Светлая/тёмная тема (или как в системе), Mica на Windows 11 / Acrylic на более старых версиях.

Разделы «Извлечение разделов» и «Терминал» — в разработке.

## Требования

- Windows 10/11 x64
- Права администратора не нужны — приложение устанавливается в профиль пользователя

## Установка

Скачайте установщик (`TweakFirmwareSetup-X.Y.Z.exe`) со страницы [Releases](https://github.com/Alxmak/BinConverter/releases) и запустите. Также доступна портативная сборка (`TweakFirmware-vX.Y.Z-win-x64.zip`) — распакуйте и запустите `TweakFirmware.exe`.

## Сборка из исходников

Требуется .NET 8 SDK.

```
dotnet build TweakFirmware.csproj
```

Тесты (`TweakFirmware.Tests`) покрывают основную логику разбивки/сборки в `TweakFirmware.Core`, включая повреждённые/пропущенные части и нехватку места на диске:

```
dotnet test
```

Установщик собирается через Inno Setup (`installer/Setup.iss`) из результата `dotnet publish`; версия передаётся параметром `/DMyAppVersion=X.Y.Z`. Полный процесс сборки и релиза — в `.github/workflows/release.yml`.

## Структура проекта

- `TweakFirmware.Core` — логика разбивки/сборки/хэширования, без зависимостей от UI
- `TweakFirmware.Tests` — тесты для `Core`
- `Views` / `ViewModels` — интерфейс (WPF, MVVM, WPF-UI)
- `Services` — сквозные сервисы приложения (тема, язык, автообновление, журнал, настройки)
- `installer` — скрипт установщика Inno Setup
