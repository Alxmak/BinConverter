# Tweak Firmware

Программа для Windows: конвертирование и сборка файлов прошивок, извлечение и объединение разделов, проверка хэш-сумм.

Части нужны потому, что программаторы не принимают файл целиком, если он больше их предела.

![Проверка сборки](https://github.com/Alxmak/BinConverter/actions/workflows/build-check.yml/badge.svg)

## Что умеет

**Конвертирование.** Режет `.bin` на части. Размер берётся из пресета программатора (TNM5000, RT809H) или задаётся вручную. После нарезки может пересчитать SHA-256 и убедиться, что ни один байт не потерян.

**Сборка файла.** Склеивает части обратно. Достаточно указать любую из них — остальные найдутся сами. Если хэш исходного файла известен, впишите его, и программа сверит результат.

**Извлечение разделов** (Beta). Находит в дампе прошивки таблицу разделов и вытаскивает разделы в отдельные файлы. Понимает разметку двадцати пяти видов — от обычных MBR и GPT до таблиц MediaTek, MStar, LG, Samsung, Amlogic, Novatek, Rockchip, Ambarella и телевизоров Sony, у которых таблицы нет вовсе и границы восстанавливаются по опорным точкам. Внутри разделов опознаёт файловые системы: ext4, SquashFS, FAT16/FAT32, ROMFS, CRAMFS, VDFS и архивы tar. Дампы NAND читает сквозь служебные области spare и умеет разрезать их на main и spare. Из прошивок Android достаёт модель, версию и производителя. Список разделов сохраняется в файл `.udev` для программатора, а рядом кладётся `analysis.json` — короткий отчёт о том, что программа увидела в дампе: разметка, разделы, замечания. Его можно приложить к вопросу вместо самого дампа.

Помечен Beta не для красоты: это перенос чужого алгоритма (скрипт Partitions_finder для программатора UFPI), и на настоящих дампах в этом виде он ещё не проверялся. Разбор оригинала и список непроверенных мест — в `docs/partitions-finder-port.md`.

**Объединение разделов.** Обратная сборка дампа из вытащенных разделов. Раздел пока не сделан.

**Проверка SHA-256.** Сравнивает от двух до пяти файлов и группирует совпавшие. Сразу видно, какой из них выбивается. До запуска показывает размеры выбранных файлов — если они разные, читать гигабайты незачем.

Долгую операцию можно приостановить или отменить. Недописанные файлы при этом удаляются: такой файл выглядит готовой прошивкой, а данные в нём неполные.

Всё происходящее попадает в журнал. Он общий для всех разделов, любую строку можно скопировать, а весь журнал — сохранить в файл.

Ещё: русский и английский с переключением на ходу; светлая тема, тёмная или как в системе; новую версию программа находит на GitHub сама и предлагает поставить одной кнопкой.

## Установка

Нужна Windows 10 или 11, 64 бита. Права администратора не требуются — программа ставится в профиль пользователя.

На странице [Releases](https://github.com/Alxmak/BinConverter/releases) два файла:

- `TweakFirmwareSetup-X.Y.Z.exe` — установщик;
- `TweakFirmware-vX.Y.Z-win-x64.zip` — портативная версия, распаковать и запустить `TweakFirmware.exe`.

## Сборка из исходников

Нужен .NET 8 SDK.

```
dotnet build TweakFirmware.csproj
dotnet test
```

Установщик собирает Inno Setup по `installer/Setup.iss`. Как собирается релиз целиком — в `.github/workflows/release.yml`.

## Как устроено

- `TweakFirmware.Core` — нарезка, склейка, хэши, разбор разделов и файловых систем, тексты интерфейса. Про сам интерфейс не знает, поэтому покрыта тестами.
- `TweakFirmware.Tests` — тесты к ней.
- `Views`, `ViewModels` — окно (WPF, MVVM, WPF-UI).
- `Services` — тема, язык, журнал, обновление, настройки.
- `installer` — скрипт установщика.
